# ระบบคัดกรองผู้สมัครงานอัตโนมัติ (Candidate Screening Engine) 🚀
> **ระบบคัดกรองและประเมินเรซูเม่ผู้สมัครงานระดับ Commercial-Grade**  
> ขับเคลื่อนด้วยปัญญาประดิษฐ์ Google Gemini GenAI (`gemini-2.5-flash`) และระบบจัดกลุ่ม HR Natural Break & Gap Analysis Tiering

---

## 📌 1. ภาพรวมระบบ (System Overview)

**Candidate Screening Engine** คือเครื่องมือช่วยงานรีครูทเตอร์และฝ่ายทรัพยากรบุคคล (HR) อัตโนมัติ ที่ออกแบบมาเพื่อลดเวลาในการอ่านเรซูเม่และประเมินคุณสมบัติของผู้สมัครงานจำนวนมาก

ระบบสามารถอ่านเอกสาร Job Description (JD) และเรซูเม่ (CV) ได้หลากหลายรูปแบบ ทั้ง **PDF** (รองรับทั้งไฟล์ PDF ปกติและไฟล์ PDF สแกนที่เป็นรูปภาพ), **Microsoft Word (.docx)** และ **ไฟล์ข้อความธรรมดา (.txt)** โดยทำการเปรียบเทียบคุณสมบัติของผู้สมัครกับความต้องการของตำแหน่งงาน วิเคราะห์จุดแข็ง-จุดที่ยังขาด และจัดลำดับผู้สมัครออกเป็น 3 กลุ่ม (Tiers) ตามเกณฑ์ HR ได้แก่ **🟢 Shortlist (ผู้สมัครที่ผ่านคัดเลือก)**, **🟡 Longlist (ผู้สมัครสำรอง)** และ **🔴 Filtered Out (ผู้สมัครที่ไม่ผ่านเกณฑ์)** พร้อมส่งออกรายงานสรุปสำหรับผู้บริหารและคณะกรรมการสัมภาษณ์ทันที

### ความสามารถหลักของระบบ
- **รองรับเอกสารหลากหลายรูปแบบ**: อ่านไฟล์ `.pdf`, `.docx`, `.doc`, `.txt` และ `.md` ได้โดยตรง
- **รองรับ PDF สแกน (Scanned PDF OCR)**: ทำงานร่วมกับ Google Gemini 2.5 Flash ในการอ่านไฟล์ PDF ที่เป็นรูปภาพสแกนได้โดยอัตโนมัติ
- **จัดกลุ่มผู้สมัครตามเกณฑ์ HR อัตโนมัติ**: คำนวณคะแนนความเหมาะสม (0–100) และจัดกลุ่มผู้สมัครเป็น **Shortlist**, **Longlist** และ **Filtered Out**
- **ส่งออกรายงาน 3 รูปแบบ**: สร้างไฟล์สรุปผลในรูปแบบ Microsoft Word (`.docx`), Microsoft Excel (`.xlsx`) และ Markdown (`.md`) พร้อมใช้งาน

## ⚡ 2. คู่มือการใช้งาน 3 ขั้นตอนง่ายๆ (สำหรับผู้ใช้ทั่วไป)

การใช้งานระบบคัดกรอง **ไม่จำเป็นต้องมีความรู้ด้านการเขียนโค้ด** เพียงทำตาม 3 ขั้นตอนง่ายๆ ดังนี้:

```
workspace/
├── _JOB_TEMPLATE/               <-- โฟลเดอร์ต้นแบบสำหรับก๊อปปี้สร้างตำแหน่งงานใหม่
│   ├── jd/                      <-- วางไฟล์ Job Description ในนี้
│   └── cv/                      <-- วางไฟล์เรซูเม่ผู้สมัครทั้งหมดในนี้
└── run_screening.bat            <-- ดับเบิ้ลคลิกเพื่อเริ่มคัดกรอง
```

### ขั้นตอนที่ 1: คัดลอกโฟลเดอร์ `_JOB_TEMPLATE`
- คลิกขวาที่โฟลเดอร์ `_JOB_TEMPLATE` เลือก **Copy (คัดลอก)**
- คลิกขวาในพื้นที่ว่างแล้วเลือก **Paste (วาง)** ในโฟลเดอร์เดียวกัน
- เปลี่ยนชื่อโฟลเดอร์ใหม่ตามชื่อตำแหน่งงานที่ต้องการ (เช่น `Job-03_Head of Science`)

### ขั้นตอนที่ 2: วางไฟล์ JD และเรซูเม่ผู้สมัคร
- เปิดโฟลเดอร์ตำแหน่งงานที่เพิ่งสร้างขึ้น (เช่น `Job-03_Head of Science`)
- เข้าไปที่โฟลเดอร์ย่อย `jd/` แล้วนำไฟล์ **Job Description** (ไฟล์ PDF, Word หรือ TXT) มาวางไว้
- เข้าไปที่โฟลเดอร์ย่อย `cv/` แล้วนำไฟล์ **เรซูเม่ / CV ผู้สมัครทุกคน** (ไฟล์ PDF, Word หรือ TXT) มาวางไว้

### ขั้นตอนที่ 3: ดับเบิ้ลคลิกไฟล์ `run_screening.bat`
- ในโฟลเดอร์ตำแหน่งงาน ให้ดับเบิ้ลคลิกที่ไฟล์ `run_screening.bat`
- หน้าต่างสีดำ (Command Prompt) จะเปิดขึ้นและทำการคัดกรองผู้สมัครทั้งหมดโดยอัตโนมัติ
- เมื่อระบบทำงานเสร็จสิ้น ไฟล์รายงานสรุปทั้ง 3 รูปแบบจะถูกสร้างขึ้นในโฟลเดอร์ตำแหน่งงานทันที!

## 📊 3. คำอธิบายไฟล์รายงานสรุปผล (Output Reports)

เมื่อระบบทำงานเสร็จเรียบร้อย จะสร้างไฟล์รายงานสรุปผล 3 รูปแบบ ดังนี้:

| ชื่อไฟล์ | รูปแบบไฟล์ | วัตถุประสงค์และการนำไปใช้งาน |
| :--- | :---: | :--- |
| **`Candidate_Summary.docx`** | Microsoft Word | **รายงานสำหรับผู้บริหารและคณะกรรมการสัมภาษณ์**: ออกแบบรูปเล่ม A4 1 หน้ากระดาษตาม Harrow Brand Identity (โทนสีน้ำเงินเข้ม Navy & ทอง Gold) แสดงคะแนนความเหมาะสม, จุดแข็งหลัก, จุดที่ยังขาด, ข้อเสนอแนะเชิงบริหาร และลิงก์สำหรับคลิกเปิดเรซูเม่ผู้สมัคร เหมาะสำหรับพิมพ์หรือส่งให้กรรมการสัมภาษณ์ |
| **`Candidate_Summary.xlsx`** | Microsoft Excel | **ตารางติดตามและกรองข้อมูลสำหรับ HR**: จัดหมวดหมู่ผู้สมัครด้วยแถบสี (🟢 Shortlist, 🟡 Longlist, 🔴 Filtered Out) พร้อมสูตร HYPERLINK สำหรับคลิกเปิดไฟล์เรซูเม่, คะแนน, จุดแข็ง-จุดอ่อน และสรุปประสบการณ์/การศึกษาอย่างเป็นระบบ เหมาะสำหรับ HR ในการคัดกรองและเรียงลำดับข้อมูล |
| **`Candidate_Summary.md`** | Markdown | **รายงานรูปแบบข้อความด่วน**: สรุปผลเนื้อหาในรูปแบบ Markdown สำหรับเปิดดูผ่าน Text Editor หรือนำไปใช้ในระบบคลังข้อมูลภายใน |

## 🔑 4. คำแนะนำการขอใช้งาน API Key (Google Gemini AI)

### API Key คืออะไร?
**API Key** เปรียบเสมือน "รหัสผ่านส่วนตัว" หรือกุญแจดิจิทัลที่อนุญาตให้ระบบ Candidate Screening Engine เชื่อมต่อไปยังระบบปัญญาประดิษฐ์ Google Gemini AI เพื่ออ่านและวิเคราะห์เรซูเม่ได้อย่างปลอดภัย

### ขั้นตอนการขอสร้าง Google Gemini API Key (ฟรี)
1. เปิดเว็บเบราว์เซอร์แล้วเข้าไปที่ **[Google AI Studio](https://aistudio.google.com/app/apikey)** (`https://aistudio.google.com/app/apikey`)
2. ลงชื่อเข้าใช้ด้วยบัญชี Google / Gmail ของคุณ
3. คลิกปุ่มสีฟ้า **"Create API key"** (หรือ **"Get API key"**)
4. เลือก **"Create API key in new project"**
5. คัดลอก (Copy) รหัส API Key ที่ปรากฏขึ้น (จะเป็นข้อความยาวๆ ที่ขึ้นต้นด้วย `AIzaSy...`)

### วิธีการกรอก API Key ในการใช้งานครั้งแรก
- เมื่อคุณดับเบิ้ลคลิก `run_screening.bat` ครั้งแรก หากระบบยังไม่มี API Key จะมีข้อความแจ้งเตือนขึ้นมา:
  ```text
  ============================================================
  🔑 GEMINI_API_KEY / GOOGLE_API_KEY not found in environment or .env file.
  ============================================================
  Please enter your GEMINI_API_KEY:
  ```
- **วางรหัส API Key**: คลิกขวาในหน้าต่างสีดำ หรือกด `Ctrl + V` เพื่อวางรหัส API Key จากนั้นกดปุ่ม `Enter`
- **ระบบบันทึกอัตโนมัติ (Self-Healing)**: ระบบจะบันทึก API Key ลงในไฟล์ `.env` โดยอัตโนมัติ ทำให้ในการใช้งานครั้งต่อไป คุณจะไม่ต้องกรอกรหัสนี้อีกเลย
